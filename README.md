# 💸 Expense Tracker App

A personal finance management app built using **Flutter**, allowing users to track daily expenses, view summaries, and back up data securely to **Google Drive**.

## 📱 Features

- **Add Daily Expenses**  
  Easily input your daily spending with item names and amounts.

- **Expense History List**  
  View a list of expenses grouped by day for better organization.

- **Detailed Daily View**  
  Tap on any date to see all individual expenses for that day.

- **Expense Summary (Graph View)**  
  Visualize spending trends over time with clean and interactive graphs.

- **Backup & Restore with Google Drive**  
  Upload your data to Google Drive and restore it anytime for safety and portability.

- **Clean & Intuitive UI**  
  A responsive, user-friendly interface optimized for both mobile and tablet devices.

## 🛠 Tech Stack

- **Flutter**
- **SQLite** – for local data storage
- **Google Drive API** – for cloud backup/restore
- **Bloc** – for state management
- **Graph Library** – for visualizing expense summaries

## 🚀 Getting Started

1. Clone the repository  
   `git clone https://github.com/yourusername/expense-tracker.git`

2. Install dependencies  
   `flutter pub get`

3. Run the app  
   `flutter run`
   
> Note: You’ll need to set up Google Drive API credentials for backup functionality.
